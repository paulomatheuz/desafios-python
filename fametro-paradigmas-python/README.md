# 🐍 Fametro University Center: Programming Paradigms (Python)

Repositório dedicado às atividades desenvolvidas durante a disciplina de **Paradigma de Linguagem de Programação em Python**, cursada no **4º período do curso de Engenharia de Software** no **Centro Universitário Fametro**.

Aqui registro exercícios, listas, desafios e pequenos projetos desenvolvidos ao longo da matéria, utilizando a **linguagem Python** para colocar em prática os conceitos apresentados durante as aulas.

A proposta deste repositório é documentar minha **evolução prática durante a disciplina**, acompanhando o estudo dos fundamentos da linguagem, a resolução de problemas e as diferentes formas de organizar e desenvolver programas.

## Sobre o repositório

Durante a disciplina, os conceitos de programação são trabalhados por meio de atividades práticas e exercícios desenvolvidos em código.

Por isso, este repositório reúne atividades como:

- exercícios desenvolvidos durante as aulas;
- listas de exercícios propostas na disciplina;
- desafios para praticar lógica de programação;
- aplicação dos fundamentos da linguagem Python;
- prática de funções, módulos e estruturas de dados;
- pequenos programas e sistemas desenvolvidos para fixação;
- experimentos e testes realizados durante o processo de aprendizagem.

Os diretórios são organizados por listas, exercícios ou pequenos projetos, permitindo que cada atividade seja consultada separadamente.

Alguns códigos podem ser bastante simples — e isso é intencional.

O objetivo é manter um registro organizado das atividades realizadas durante a disciplina e acompanhar minha evolução ao longo do **4º período da graduação**, desde os primeiros exercícios até soluções mais estruturadas.
