# 🐍 Desafios Python

Repositório dedicado à minha jornada de aprendizado em **Python**.

Aqui registro exercícios, desafios e pequenos projetos desenvolvidos enquanto acompanho videoaulas, cursos e outros materiais de estudo.

A proposta deste repositório não é reunir aplicações complexas, mas documentar minha **evolução prática na linguagem**, desde os conceitos mais básicos até projetos gradualmente mais completos.

---

## 📚 Sobre o repositório

Durante meus estudos, procuro transformar cada conceito aprendido em código.

Por isso, este repositório reúne atividades como:

- exercícios de lógica de programação;
- desafios propostos durante as aulas;
- testes de novos conceitos;
- pequenos scripts;
- projetos simples para praticar vários conceitos em conjunto;
- experimentos feitos durante o processo de aprendizagem.

Alguns códigos podem ser bastante simples — e isso é intencional.

O objetivo é conseguir olhar para este repositório no futuro e acompanhar claramente a minha evolução, desde os primeiros programas até projetos mais estruturados.

---

## 🎯 Objetivos

Com este repositório, pretendo:

- praticar constantemente os conceitos estudados;
- melhorar minha lógica de programação;
- ganhar familiaridade com a sintaxe do Python;
- desenvolver autonomia para resolver problemas;
- aprender boas práticas de organização de código;
- acompanhar minha evolução ao longo do tempo;
- construir uma base sólida antes de avançar para projetos maiores.

---

## 🧠 Metodologia de estudo

Meu processo de aprendizado segue, de forma geral, este fluxo:

```text
Videoaula / Conteúdo
        ↓
Entendimento do conceito
        ↓
Exemplo prático
        ↓
Exercício ou desafio
        ↓
Pequeno projeto
        ↓
Revisão e melhorias
```

Sempre que possível, tento escrever o código por conta própria antes de consultar uma solução pronta.

Também posso voltar a projetos antigos para refatorá-los conforme aprender novas técnicas.

> A ideia não é começar escrevendo código perfeito, mas conseguir escrever hoje um código melhor do que eu escrevia ontem.
