# 🐍 Fundamentos Python

Repositório dedicado à minha jornada de aprendizado em **Python**, reunindo conteúdos acadêmicos, exercícios, desafios e projetos desenvolvidos ao longo da minha formação.

Atualmente, curso o **4º período de Engenharia de Software** no **Centro Universitário Fametro**. Durante esse período, continuarei publicando as atividades da disciplina de **Paradigma de Linguagem de Programação em Python**.

Além da graduação, concluí a formação **Developer em Python**, da **FIAP**, experiência que contribuiu para fortalecer minha base na linguagem e em desenvolvimento de software.

Paralelamente, iniciei o [**Curso de Python 3 do básico ao avançado — com projetos reais**](https://www.udemy.com/course/python-3-do-zero-ao-avancado/). Pretendo concluir integralmente o curso, acompanhando todos os conteúdos, exercícios e projetos propostos.

## Conteúdos que pretendo estudar

Ao longo dessa jornada, pretendo estudar e praticar:

- fundamentos de Python e lógica de programação;
- programação procedural e funcional;
- programação orientada a objetos;
- funções, módulos, pacotes e ambientes virtuais;
- tratamento de erros e manipulação de arquivos;
- interfaces gráficas com PySide6;
- automação com Selenium;
- desenvolvimento de aplicações e APIs com Django;
- bancos de dados relacionais;
- testes automatizados e TDD;
- padrões de projeto;
- projetos práticos do básico ao avançado.

A organização dos conteúdos será ampliada gradualmente conforme eu avançar na faculdade e no curso.
